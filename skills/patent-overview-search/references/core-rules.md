# 概要专利检索独立规则

## 两种模式
普通技术描述即可做strategy模式：交技术方向画像、对象/问题/关系/手段/功能/效果的词组、同义词和分层查询、地域/语言/日期边界、来源与取得计划、停止条件及未覆盖项。未实际查询不得列假文献或写检索完成。
search模式需实际可用工具和已获准范围；先读[检索工具适配](tool-adapter.md)。用户提供的返回可做provided_results_review，保留取得身份及未复核范围，不能冒称本包实际检索。真实返回逐件回读身份和摘要，按公开号/同族/版本处理去重，保留原记录和方向归属。
## 摘要筛选
按实质不同方向建立画像并保留共享候选的多方向关系。按详细规则的两阶段、逐方向池与配额实施，有工具/预算缺口如实列出，不以凑数补文献。全池候选逐件处置，输出最多20件并保留未选原因和重要未读线索。题名不能代替摘要；摘要相关性与完整机制的证据程度分别说明，overview_overlap_risk=not_assessed，不把高相关叫高风险，不输出已完成新颖性或全文判断。图未读只列未核，不补画或假称代表图已检查。

## 详细规则与自检

按[授权技术条款](business-rules.md)逐项核技术链、条件、范围、来源和对应成果；其中旧输入/历史治理不成为独立前置。交付前对照实际材料核所有重要对象、关系、数值、逻辑、实施路径、效果证据、支持/引用、人工改动、未读范围与全部开放警示。可在本次授权内修正生成遗漏，不能把本轮漏项推成用户缺件。自检、独立审阅、技术确认、专业接受、可提交各自留证，不用格式、分数或保存成功代替内容判断。
