# 说明书正式稿辅助独立规则

## 完善正文
直接用当前权项、待完善说明书和实际技术依据；图/实验依涉及内容实际读取，不要求M11或旧T表。交技术领域、背景、发明内容、附图说明、具体实施方式与摘要，正文可编辑、术语/参数/步骤一致。按机械、控制软件、材料工艺领域说明实体/关系、作用机制、条件及至少一条实施路径，未成立继续未成立。
逐权项真实父链核T4支持、概括范围、实施矩阵与效果证据。润色不能让未知效果成立；原单点不无据变范围、实施例不假装有代表性、后补数据不变原始公开。图未读不能核图通过，图文冲突保留双源而非选有利项。权项范围不自行改，必要变更给具名建议。
## 局部修订与交付
按准确对象修订，未涉及技术及原文字节能保留则保留；有意重组注明范围和对照。交完整说明书/摘要、当前权项、最终T1—T4或本次实际建立的相应表、实施/概括/效果/图文矩阵、旧新对照与本次T6说明书侧，已有T5只继承不代替策略重选。T6保留来源、原始依据是否核到、工作稿新增身份及范围影响。未得到原始申请不能由当前稿或后补实验推定可提交，新增模型解释与未证事实逐项标明。

## 详细规则与自检

按[授权技术条款](business-rules.md)逐项核技术链、条件、范围、来源和对应成果；其中旧输入/历史治理不成为独立前置。交付前对照实际材料核所有重要对象、关系、数值、逻辑、实施路径、效果证据、支持/引用、人工改动、未读范围与全部开放警示。可在本次授权内修正生成遗漏，不能把本轮漏项推成用户缺件。自检、独立审阅、技术确认、专业接受、可提交各自留证，不用格式、分数或保存成功代替内容判断。

## 表字段

按[本节点技术表字段](table-contracts.md)组织实际职责内的T表/支持记录；不提前生产未到本节点的表，不填空表冒充完成。
