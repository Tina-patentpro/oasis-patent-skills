# 本节点技术表字段

OasisIntWrite，2026-11-07。以下为自有链合同§2.9的授权字段摘编。只在本节点实际生产、更新或检查对应表时使用；不要求用户先填表，不因独立材料没有旧表产生缺前序警示，也不把尚未到本节点职责的表提前造出。

表可按语义使用紧凑列/同文件精确定位，但必备信息不能因压缩丢失。未知字段说明具体原因；来源/确认/证据状态按独立合同分开。T4未提供说明书时说明判断未核，不造支持位置；T5无效果或文献时如实受限；T6缺原始申请不作原始公开/修改合法性通过。继承表保留实际身份和原对象，不能用当前假设重写历史。

#### T1 技术问题表

| 必备列 | 内容要求 |
|---|---|
| `tp_id` | 技术问题稳定编号 |
| 技术对象/场景 | 问题出现的对象、过程和条件 |
| 现有缺陷 | 可观察的技术不足 |
| 原因或机理 | 直接记载、合理推导或待验证假设 |
| 改进目标 | 拟达到的技术状态 |
| 指标/测量方法 | 指标、单位、测量或判断方式 |
| 来源状态 | 输入ID、定位、可信状态和内容来源 |

#### T2 完整技术要素表

| 必备列 | 内容要求 |
|---|---|
| `solution_id`、`macro_id`、`feature_id` | 方案、宏特征、元特征稳定编号 |
| 关联`tp_id` | 所解决的技术问题 |
| 元实体 | 对象、部件、材料、数据或步骤载体 |
| 元关系 | 连接、位置、依赖、交互、时序、因果、转换或协同关系 |
| 元手段 | 结构、步骤、算法、工艺或控制方式 |
| 元功能 | 元手段直接实现的技术作用 |
| 元效果 | 元特征产生的局部结果 |
| 必要性 | 独权必要、从权优选、可替代或仅实施例 |
| 来源状态 | 输入ID、定位、可信状态和内容来源 |

#### T3 技术效果及证据表

| 必备列 | 内容要求 |
|---|---|
| `te_id` | 整体技术效果稳定编号 |
| 关联`tp_id` | 所解决的技术问题 |
| 关联特征或组合 | 产生效果的`feature_id` |
| 作用机理 | 特征如何产生效果 |
| 成立条件和边界 | 参数、环境、对象、组合或操作条件 |
| 指标/测量方法 | 实验、仿真、计算或可验证观察 |
| 证据状态 | 已验证、直接记载、合理推导或待验证 |

#### T4 权利要求—说明书支持表

| 必备列 | 内容要求 |
|---|---|
| 权利要求号/特征序号 | 被检查的权项内容 |
| `feature_id` | 对应技术要素 |
| 说明书支持 | 段落、实施例、附图或表格定位 |
| 技术作用 | 对应技术问题、功能和效果 |
| 概括层级 | 具体方式、并列选择或上位概括 |
| 支持结论 | 充分、部分、缺失或建议限缩 |

#### T5 创造性论证表

| 必备列 | 内容要求 |
|---|---|
| 权利要求 | 被评价权项 |
| 最接近现有技术候选 | 工作流建议、接近理由、证据、置信度和人工判断状态 |
| 区别特征或组合 | 相互作用的特征不得任意拆散 |
| 区别特征产生的效果 | 应能从申请文件技术内容获知 |
| 实际解决的技术问题 | 不含区别特征或对区别特征的暗示 |
| 技术启示分析 | 结合动机、实现路径、成功预期和技术障碍 |
| 结论强度 | 强、中、弱或证据不足，并说明原因 |
