# 制图规则入口

OasisIntWrite于2026-11-07基于自有I01 V0.2.1改编。原生成／编辑／结果合同的语义保留，本版去除历史提示与私有应用依赖，不改变已证缺图分流。

- 新图只读取[生成规则](generation.md)：保留全部部件／节点、数量、方向、连接、条件及指定视图；实际生成后查看结果。
- 原图修改只读取[编辑规则](editing.md)：真实传入原图；深度结构变化必须实际改变数量／关系，其他区域及透明背景保真；跨图编号／视图同步。
- 两模式共用[结果状态](result-contract.md)：明确失败、未知、正在执行、成功但产物不可访问及真实可读取结果分别处理，逐图核验，不自动重发未知任务。

结构图、流程图、图中标签和物理技术含义分别核对。数量或箭头错误不能以提示词或接口成功辩解；没有看清的细节列未核。默认专利图白底黑线；用户明确媒介、颜色、格式、尺寸及背景要求优先保留。

本包不提供技术真实性、可实施性、申请格式或提交就绪性的自动认证。使用实际工具前核本次任务与材料范围；图像源的权利和实际提供方条件不由本包软件许可代替。
