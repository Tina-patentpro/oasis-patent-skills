# 说明书初稿独立规则

## 从权项与交底起草
直接读取当前权项和对应交底；只有权项仍交支持缺件稿，不要求M06或已有T4。交技术领域、背景、发明内容、附图说明、具体实施方式和摘要，形成问题—方案—效果对应，保留申请类型和术语。
核至少一条实施路径：机械空间/连接/受力/运动，软件控制输入/数据/触发/模块交互/时序，工艺材料物料/条件/步骤/状态转变。说明关键关系、作用机理、参数与边界；没有连接或执行条件不能补成确认实施例。已有一般关系可作有据解释，新增技术事实逐项待确认。
## 支持与交付
逐权项/真实父链形成T4完整初版、可实施性矩阵、概括范围测试、效果证据矩阵、附图计划和标记映射。逐效果关联特征/组合、条件、指标、机理、证据类型及限制；模型推导与期望不变实测；原单点不无据扩范围。路径未成立显式写未成立及缺口，不能因五章齐全称公开充分。当前权项保留原文，发现范围问题给建议，不自动改权项。初稿质量、技术确认和正式用途分列，默认一次有界试写。

## 详细规则与自检

按[授权技术条款](business-rules.md)逐项核技术链、条件、范围、来源和对应成果；其中旧输入/历史治理不成为独立前置。交付前对照实际材料核所有重要对象、关系、数值、逻辑、实施路径、效果证据、支持/引用、人工改动、未读范围与全部开放警示。可在本次授权内修正生成遗漏，不能把本轮漏项推成用户缺件。自检、独立审阅、技术确认、专业接受、可提交各自留证，不用格式、分数或保存成功代替内容判断。

## 表字段

按[本节点技术表字段](table-contracts.md)组织实际职责内的T表/支持记录；不提前生产未到本节点的表，不填空表冒充完成。
